# Pressure Sensor for Flat Irons

## First Time Setup (do once)

1. Go to this page on GitHub
2. Click setup.bat
3. Click Download raw file
4. Double click setup.bat — it does everything automatically!

## Every Time After

1. Plug in USB from Arduino
2. Double click start_sensors.bat on your Desktop
3. Data saves automatically to a CSV file on your Desktop
4. Press Ctrl+C to stop recording
