# Pressure Sensor for Flat Irons

## First Time Setup (do once)

1. Install Python from python.org (check "Add Python to PATH" during install)
2. Open Command Prompt and type: pip install pyserial
3. Download pressure.py and start_sensors.bat from this page and save both to your Desktop

## Every Time After

1. Plug in USB from Arduino
2. Double click start_sensors.bat on your Desktop
3. Data saves automatically to a CSV file on your Desktop
4. Press Ctrl+C to stop recording

## Downloading the Files

1. Click on pressure.py
2. Click Download raw file
3. Save to Desktop
4. Repeat for start_sensors.bat
